### Knowledge Graph Analysis of Korea University Seoktap Daedongje (2025–2026)

고려대학교 「디지털인문학응용」 수업의 팀 프로젝트로, 2025년과 2026년 석탑대동제의 연예인 섭외, 학생 공연, 조직 및 학생단체의 부스 운영 현황을 Neo4j 기반 지식그래프로 구축하고 분석한 프로젝트입니다.

- 대학 축제 기획 및 마케팅 관점에서 활용할 수 있는 기초 자료 구축

### 4.3 지식그래프 구조

본 프로젝트에서는 축제와 참여 주체를 직접 연결하는 방식뿐 아니라, 축제의 개최 일자를 매개로 관계를 표현하였습니다.

축제와 일자:

`(축제)-[:HAS_DAY]->(일자)`

공연 참여:

`(연예인 또는 학생참여주체)-[:PERFORMED_IN]->(일자)`

부스 운영:

`(조직 또는 학생참여주체)-[:OPERATED_BOOTH_IN]->(일자)`

이 구조를 통해 특정 주체가 어느 연도의 축제에 참여했는지뿐 아니라, 정확히 어느 일자에 공연하거나 부스를 운영했는지 확인할 수 있습니다.

또한 두 연도에 걸쳐 반복적으로 참여한 주체를 추출하고, 운영 기간과 참여 유형을 비교할 수 있습니다.

## 7. 주요 Cypher 쿼리

### 7.1 연도별 부스 운영 주체 수 비교

```cypher
MATCH (f:축제)-[:HAS_DAY]->(d:일자)
MATCH (n)-[:OPERATED_BOOTH_IN]->(d)
WHERE f.year IN [2025, 2026]
  AND (n:조직 OR n:학생참여주체)

WITH f.year AS 연도, collect(DISTINCT n) AS 참여주체

RETURN
    연도,
    size([n IN 참여주체 WHERE n:조직]) AS 외부조직,
    size([n IN 참여주체 WHERE n:학생참여주체]) AS 학생참여주체,
    size(참여주체) AS 합계
ORDER BY 연도;
```

### 7.2 두 연도 모두 부스를 운영한 학생참여주체

```cypher
MATCH (s:학생참여주체)-[:OPERATED_BOOTH_IN]->(d:일자)
MATCH (f:축제)-[:HAS_DAY]->(d)
WHERE f.year IN [2025, 2026]

WITH s, collect(DISTINCT f.year) AS 참여연도

WHERE 2025 IN 참여연도
  AND 2026 IN 참여연도

RETURN
    s.name AS 학생참여주체,
    참여연도
ORDER BY 학생참여주체;
```

### 7.3 연도별 일차별 부스 운영 관계 수

```cypher
MATCH (f:축제)-[:HAS_DAY]->(d:일자)
MATCH (n)-[r:OPERATED_BOOTH_IN]->(d)
WHERE f.year IN [2025, 2026]
  AND (n:조직 OR n:학생참여주체)

RETURN
    f.year AS 연도,
    d.name AS 운영일자,
    count(r) AS 운영관계수
ORDER BY 연도, 운영일자;
```

### 7.4 운영 기간별 참여 주체 수 비교

```cypher
MATCH (f:축제)-[:HAS_DAY]->(d:일자)
MATCH (n)-[:OPERATED_BOOTH_IN]->(d)
WHERE f.year IN [2025, 2026]
  AND (n:조직 OR n:학생참여주체)

WITH
    f.year AS 연도,
    n,
    count(DISTINCT d) AS 운영일수

RETURN
    연도,
    운영일수,
    count(n) AS 운영주체수
ORDER BY 연도, 운영일수;
```

### 7.5 부스 운영 관계 그래프 시각화

```cypher
MATCH path =
    (n)-[:OPERATED_BOOTH_IN]->(d:일자)
    <-[:HAS_DAY]-(f:축제)
WHERE f.year IN [2025, 2026]
  AND (n:조직 OR n:학생참여주체)

RETURN path;
```

위 쿼리는 축제, 일자, 부스 운영 주체 사이의 연결 관계를 Neo4j 그래프 형태로 시각화합니다.

- 두 연도에 모두 참여한 주체의 탐색

## 9. 분석의 한계

본 프로젝트의 결과는 수집된 자료와 구축된 지식그래프에 기반합니다.

부스 운영 관계 수는 특정 주체가 특정 일자에 부스를 운영했다는 관계의 개수를 의미하며, 실제 설치된 물리적 부스의 개수나 방문객 수를 의미하지 않습니다.

또한 학생참여주체의 비중 증가가 축제 운영 정책의 변화로 인해 발생했는지, 외부 조직의 참여 감소가 특정한 의사결정의 결과인지는 현재 데이터만으로 확정할 수 없습니다.

따라서 분석 결과는 확인된 참여 구조와 운영 양상의 변화에 초점을 맞추어 해석하였습니다.

## 10. 프로젝트 의의

본 프로젝트는 대학 축제의 구성 요소를 개별 정보가 아닌 관계 중심의 데이터로 구조화했다는 점에서 의의가 있습니다.

2025년과 2026년 석탑대동제의 참여 현황을 비교한 결과, 전체 부스 운영 주체의 수는 증가했지만 외부 조직의 참여 수는 감소하고 학생참여주체의 비중은 상승하였습니다.

또한 2026년에는 단기간 부스 운영에 참여하는 주체가 증가하고 축제 마지막 날의 운영 관계 수가 감소하는 특징이 나타났습니다.

이를 통해 지식그래프가 대학 축제의 참여 구조와 연도별 변화를 분석하는 데 유용한 방법임을 확인하였습니다.

나아가 본 프로젝트의 데이터와 분석 방식은 향후 대학 축제의 프로그램 구성, 참여 주체 관리, 행사 기획 및 마케팅 전략 수립을 위한 참고 자료로 활용될 수 있습니다.
